Privacy, limits & what the results mean

This single file runs locally in your browser. No server, telemetry, accounts, API calls or external libraries. Files are read into memory; originals are never changed. Clear results or close this tab to release this tool’s references. Exports are new files saved by your browser.

Duplicates mean identical SHA-256 file hashes, not visually similar images. “Alpha channel” describes the PNG encoding; “transparent pixels” includes any decoded alpha below 255. Palette/tRNS transparency is supported. Pixel values are browser-decoded 8-bit values; this is not a color-management or lossless metadata-validation tool.

Static PNG only: APNG is rejected. Maximum edge: 8,192 pixels. Oversized batches are rejected as a whole; per-file failures are listed. Files are scanned sequentially, with responsive cancellation checkpoints. Cancellation cannot interrupt an in-flight browser decode or hash. Resource limits reduce, but cannot eliminate, memory pressure on low-memory devices. A partial scan exports only processed files.

Contact sheets contain successful files, in selection order, with numbered filename labels (long names may be shortened); CSV preserves full names. CSV text fields are quoted and formula-leading values are prefixed with an apostrophe. Spreadsheet handling varies: import text columns as text. Exports include filenames: review them before sharing.

Browser testing is not yet verified. Automated parser and CSV checks passed; rendering, downloads and browser-specific behavior still need verification. Requires a modern browser with Canvas, Blob downloads and Web Crypto on local files.
